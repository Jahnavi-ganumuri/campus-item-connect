# Lost & Found Hub

A responsive Lost & Found web application built with **Next.js, React, TypeScript and CSS**.

## Features

- Login and signup
- Demo authentication using browser localStorage
- Lost and found item reporting
- Required image upload with local preview
- Search and category/status filtering
- Dynamic item details
- Dashboard with personal posts
- Edit and delete posts
- Mark items as resolved
- Working profile page
- Responsive desktop/mobile UI
- Sample data for first-time use
- Clean reusable React components

## Tech Stack

- Next.js
- React
- TypeScript
- CSS
- Browser localStorage
- Git/GitHub

## Run locally

```bash
npm install
npm run dev
```

Open:

```text
http://localhost:3000
```

## Demo account

You can create an account from the Sign Up page.

For demo purposes, data is stored in your browser's localStorage. This means the project works without setting up MongoDB or Firebase.

## Important

This is a portfolio/demo application. For production deployment, authentication should use a secure server-side system and uploaded images should use cloud storage such as Cloudinary, Firebase Storage, or S3.
